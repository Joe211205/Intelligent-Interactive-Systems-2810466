# COMPARISON.md — template

Copy to `COMPARISON.md`. One paragraph, written in the last five minutes, comparing the agentic run
with direct prompting on the same task.

Direct prompting means: paste the failing test and the relevant file into a chat window, ask for a
fix, copy the answer back yourself, and run the tests yourself. It is a real option and sometimes
the better one. The question is not which is more impressive; it is what each one costs and what
each one lets you see.

Fill in the four numbers first, then write the paragraph. The numbers keep the paragraph honest.

| | agentic run | direct prompting |
|---|---|---|
| steps you could see | | |
| times you intervened | | |
| minutes, start to green | | |
| outcome | | |

Then one paragraph, in your own words, answering: **what did the agent do that you could not see, and
what did you see that you would not have seen otherwise?**

A good paragraph names at least one thing the agentic run cost you — waiting, an extra approval,
a step you could not follow — and at least one thing the record gave you that a chat window does
not. A paragraph that says only "it was faster" has not looked at the trace.
